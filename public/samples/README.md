# Muestras de la banda

Servidas desde `/samples/` y cacheadas por el service worker (`gigsync-samples`).

- `piano/` — Salamander Grand Piano (Alexander Holm), CC-BY 3.0, vía https://tonejs.github.io/audio/salamander/
- `organ/`, `bass/` — del repo nbrosowsky/tonejs-instruments (https://github.com/nbrosowsky/tonejs-instruments); recortadas (órgano 3 s, bajo 2 s, mono 64 kbps). El repo no declara licencia: revisar antes de distribuir la app más allá del uso personal.
- `drums/` — kit acústico de https://tonejs.github.io/audio/drum-samples/acoustic-kit/

Si se reemplaza un fichero, cambiarle el nombre (la caché es CacheFirst).
